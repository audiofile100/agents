# agents

A collection of agent instruction files.

| File | Purpose |
| --- | --- |
| `AGENTS.md` | Obsidian vault commands: `$idx` registers a note under a `::prefix`, and `::prefix <prompt>` logs a prompt and its answer to that note. |

To use one, copy or symlink it into a project folder, e.g. `ln -s ~/NAS/Github/agents/AGENTS.md AGENTS.md`.
